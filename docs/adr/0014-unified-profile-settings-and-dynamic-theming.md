# Unified Profile and Settings Hub with Dynamic Color Theming

Rather than fragmenting user account management, appearance preferences, localization, and support into disparate screens, ProjectHub centralizes all non-workspace-specific settings into a unified "Profile & Settings" view at `/profile`. This screen hosts the user profile card and edit form, language selector (English/Arabic), theme mode toggle (Dark/Light/System), a horizontal carousel for 6 curated dynamic color palettes (Deep Slate, Ocean Breeze, Sunset Ember, Forest Moss, Rose Gold, Midnight Purple), an expandable FAQ section, and client version information. The active palette and theme mode are managed by an `AppSettingsCubit`, persisted via `SharedPreferences`, and dynamically re-skin all Material 3 semantic color tokens, buttons, surfaces, and the interactive `AmbientGlowBackground` without requiring an application restart.
